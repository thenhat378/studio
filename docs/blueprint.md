# **App Name**: FixFlow Pro

## Core Features:

- Secure User Authentication: Comprehensive user authentication including login, forgotten password recovery, and mandatory first-time password change for all user roles.
- Repair Request Form & Equipment Catalog: Intuitive forms for submitting new repair requests, allowing users to select and specify items from a pre-defined and managed equipment list.
- AI-Powered Initial Request Enhancement: An AI tool that analyzes user problem descriptions to suggest potential causes, categorize the request, and recommend relevant equipment from the catalog for more precise and accurate submissions.
- Multi-Level Approval & Assignment: Implement a workflow where unit leaders can approve or reject new repair requests, followed by CSVC managers assigning approved requests to available technicians.
- Technician Task Management & Reporting: Technicians can view their assigned repair tasks, update progress statuses in real-time, and submit detailed completion reports including actions taken.
- Requester Report Validation: Enable the original request submitter to review the technician's repair completion report and provide final approval or rejection of the outcome.
- Operational Dashboard & Equipment Management: A centralized dashboard providing real-time insights into all repair requests, their current statuses, technician workload, and tools for managing the master equipment catalog.

## Style Guidelines:

- Primary color: A professional and trustworthy medium blue (#2267C4), signaling reliability and clarity for main interactive elements.
- Background color: A soft, cool light grey (#F1F5F9), providing a clean and understated canvas that aids readability and focus.
- Accent color: A vibrant cyan-blue (#14BBDB), used sparingly for calls to action, important notifications, and highlighting key information, offering dynamic contrast.
- Body and headline font: 'Inter', a modern grotesque sans-serif font known for its exceptional readability and neutral aesthetic, suitable for complex data display and clear textual content.
- Utilize a consistent set of vector-based, line icons with a professional and functional design. Icons will represent different equipment types, workflow statuses (e.g., approved, pending, completed), and user actions (e.g., assign, edit, print).
- A clean, adaptive, and highly responsive layout, featuring a collapsible sidebar for navigation and a main content area optimized for data tables, forms, and detailed dashboards, ensuring usability across various screen sizes.
- Incorporate subtle, functional animations such as smooth page transitions, clear loading indicators, and mild interactive feedback effects (e.g., button presses, form validation) to enhance the user experience without distractions.
