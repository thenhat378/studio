# Ứng dụng Quản lý sửa chữa - DUE

Ứng dụng hỗ trợ các tổ chức quản lý quy trình sửa chữa thiết bị cơ sở vật chất chuyên nghiệp trên nền tảng di động.

## 🚀 Giai đoạn 2: Kết nối với Firebase App Hosting (Chi tiết)

Nếu bạn không thấy chữ **Build**, hãy làm theo các bước sau:

1.  **Vào Firebase Console**: [console.firebase.google.com](https://console.firebase.google.com/).
2.  **Chọn dự án của bạn**.
3.  **Nhìn sang cột menu bên trái**:
    *   Tìm biểu tượng hình **Cái búa** hoặc chữ **Build** (Xây dựng).
    *   Nếu menu đang thu gọn, hãy nhấn vào biểu tượng **>>** ở dưới cùng bên trái để mở rộng.
    *   Nếu vẫn không thấy, hãy nhấn vào **"All products"** (Tất cả sản phẩm) ở cuối danh sách, sau đó tìm biểu tượng **App Hosting** trong danh sách hiện ra.
4.  **Nhấn vào App Hosting** và chọn **Get Started**.

---

## 🛠 Cách xử lý nếu lỗi Build
Tôi đã cấu hình sẵn file `apphosting.yaml`, nhưng hãy lưu ý:
- Firebase sẽ tự động chạy lệnh `npm run build`.
- Nếu Firebase hỏi **Root directory**, hãy để trống (hoặc điền `/`).
- Nếu hỏi **Settings**, hãy chọn **Next.js**.
